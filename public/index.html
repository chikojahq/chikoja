بایگانی‌شده

چی‌کجا

«چی کجاست؟»

چی‌کجا فهرستی از مکان‌های شهرهای ایران بود و حدود سال‌های ۱۳۹۲ تا ۱۳۹۴ (۲۰۱۳ تا ۲۰۱۵) فعال بود.

این پروژه اکنون بایگانی شده است و دیگر به‌روز نمی‌شود. از همهٔ کسانی که از آن استفاده کردند سپاسگزاریم.

chikoja (“what is where?”) was a directory of places in Iranian cities, active about 2013–2015. The project is now archived.
